# User story title: View restaurant menu
Other title versions: View menu items, Display menu

## Priority: 10
Customer must be able to view menu to order.

## Estimation: 1 day
Planning poker / estimates:
* Jarrod: 1 day (before iteration-1)

## Assumptions (if any):
- Each restaurant has a set of menu items (seeded or mocked).
- Menu page is reachable from restaurant list.

## Description
Description-v1: The app will show a restaurant’s menu so the customer can decide what to buy.

## Tasks (see chapter 4)
1. Create menu page/screen for a selected restaurant (0.5 days)
2. Load menu items for the selected restaurant (0.25 days)
3. Add navigation from restaurant list → menu (0.25 days)
