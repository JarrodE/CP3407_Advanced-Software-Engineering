# Initial Backlog Ideas (Draft)

Priority scale: 10 = most important, then 20/30/40/50. :contentReference[oaicite:8]{index=8}

## Customer App (Ordering)
1. **(10) Browse restaurants**
   - As a customer, I want to see a list of restaurants so I can choose where to order from.

2. **(10) View restaurant menu**
   - As a customer, I want to view a restaurant’s menu so I can decide what to buy.

3. **(10) Add items to cart**
   - As a customer, I want to add menu items to a cart so I can prepare an order.

4. **(20) Update cart quantities**
   - As a customer, I want to change quantities or remove items so my cart matches what I want.

5. **(20) Place an order**
   - As a customer, I want to place an order with delivery details so the restaurant can fulfil my request.

6. **(30) Track order status**
   - As a customer, I want to see my order status so I know what’s happening.

## Restaurant App (Menu + Orders)
7. **(10) Restaurant creates/edits menu items**
   - As a restaurant, I want to manage menu items so customers can order accurate products.

8. **(10) Restaurant views incoming orders**
   - As a restaurant, I want to see new orders so I can start preparing them.

9. **(20) Restaurant updates order progress**
   - As a restaurant, I want to update order status so customers know progress.

## Delivery (optional early, or later milestone)
10. **(40) Driver accepts a delivery**
   - As a driver, I want to accept an available delivery so I can deliver an order.
