# FeedMe (CP3407 Project)

## Overview
FeedMe is a food ordering and delivery system (a “better FoodPanda”-style app). Customers browse restaurants and menus, build a cart, place orders, and track order progress. Restaurants manage menus and incoming orders. Delivery workflow is a later milestone.

## Milestone 1.0 / MVP (baseline functionality)
Baseline functionality:
- Customer: browse restaurants/menus, add items to cart, place an order
- Restaurant: manage menu items, view incoming orders, update order status
- Customer can see order status updates

Delivery workflow (driver accepts jobs) is a later milestone.
